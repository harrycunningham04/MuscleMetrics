# Gym Website Frontend

This is the React frontend for the gym website. It interacts with the backend REST API to provide a responsive and user-friendly interface for managing gym workouts and tracking progress.

## Folder Structure
- `src/components/`: Reusable UI components (e.g., forms, charts).
- `src/pages/`: Page-level components (e.g., HomePage, SignupPage).
- `src/services/`: API integration using Axios.
- `src/styles/`: CSS/SCSS for styling.
